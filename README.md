### 📊 [GovInsight – Indian Government Budget RAG System](https://github.com/Neeharika2/gov-budget-analysis)

> *Retrieval-Augmented Generation · Semantic Search · Policy Analysis*

GovInsight is a **RAG-based intelligence system** designed for semantic querying and in-depth analysis of Indian Union Budget documents. It eliminates the manual overhead of parsing hundreds of pages of budget PDFs across multiple years, ministries, and schemes.

**Key Highlights:**

- 🔍 Semantic search over multi-year budget documents using vector embeddings
- 🏛️ Ministry and scheme-level granular query support
- 📄 Automated PDF ingestion and chunking pipeline
- 💬 Natural language Q&A interface powered by LLMs
